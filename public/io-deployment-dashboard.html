📋 DNS Configuration Instructions

  1. After deployment, copy the Replit deployment IP address
  2. Go to your .io domain registrar (e.g., Namecheap, GoDaddy)
  3. Navigate to DNS Management for your domain
  4. Add an A record:
    • Type: A
    • Host: @ (for root domain)
    • Value: [Replit IP]
    • TTL: 3600
  5. Add a CNAME record for www:
    • Type: CNAME
    • Host: www
    • Value: yourdomain.io
    • TTL: 3600
  6. Save DNS changes and wait 5-30 minutes for propagation
  7. SSL certificate will be auto-provisioned by Replit
  8. Verify deployment at https://yourdomain.io
