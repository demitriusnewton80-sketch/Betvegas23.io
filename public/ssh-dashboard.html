  1. Generate SSH Keypair
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
  2. Get Your Public Key
    cat ~/.ssh/replit.pub
  3. Add Key Above

    Copy your public key and paste it in the form above

  4. Configure SSH Client
    echo "Host *.replit.dev Port 22 IdentityFile ~/.ssh/replit StrictHostKeyChecking accept-new" >> ~/.ssh/config
